# CyberPerler

A web tool to convert your photos into custom Perler bead patterns.

Live Demo: [https://mmm1122.github.io/CyberPerler/](https://mmm1122.github.io/CyberPerler/)

## Features

- **Photo to Bead Pattern**: Upload any image and turn it into a pixelated bead blueprint.
- **Color Matching**: Automatically maps image colors to standard Perler bead palettes.
- **Adjustable Settings**: Customize grid size, resolution, and color quantization to match your pegboard dimensions.
- **Easy Export**: Save or print your pattern to use as a crafting reference.

## Getting Started

Visit the [live site](https://mmm1122.github.io/CyberPerler/) directly in your browser. No installation or setup required.
